This project is based on the Real Estate Listing Platform theme.
The website displays multiple property listings using a modern card layout and responsive design. It is built using only HTML5 and CSS3, following semantic structure and beginner-friendly coding practices.

 Features
 Real Estate Theme

Clean property cards with images, title, and price

Hero banner introducing the platform

Header with navigation links

Simple footer section

 UI & Layout

CSS Grid used for listing cards

Flexbox used for header alignment

Color palette and spacing for clean modern UI

Hover effects on cards

Proper typography and consistent styling

 Responsive Design

The site adjusts smoothly across devices:

Desktop: 3-column property grid

Tablet: 2-column grid

Mobile: 1-column stacked layout

Header collapses neatly for small screens

 Accessibility

Images include ALT text

Correct HTML semantic tags

Labels used properly in forms (if added)
