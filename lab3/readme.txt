Responsive Portfolio Webpage – Lab Assignment
 Description

This project is a responsive portfolio webpage created as part of the lab assignment.
The webpage adjusts smoothly across different screen sizes using HTML5, CSS3, and responsive design techniques such as media queries, flexible layouts, and relative units.

The goal of this lab was to understand:

How responsiveness works in web design

How layout changes across devices

How to test and verify responsive behavior

📱 Steps to View Responsive Behavior

You can test the responsiveness using your browser’s Developer Tools.

1️. Open the Webpage

Open index.html in any browser (Chrome recommended).

2️. Open Developer Tools

Press F12 or

Right-click → Inspect
3. Switch to Mobile View

Click the Toggle Device Toolbar (📱 icon) in the top-left of DevTools.

4. Test Different Breakpoints

The layout has been tested using these common breakpoints:

Device Type	Width (px)
Small Mobile	320px – 480px
Medium Mobile	481px – 576px
Large Mobile / Small Tablet	577px – 768px
Tablet	769px – 1024px
Laptop / Small Desktop	1025px – 1366px
Large Desktop	1367px and above
5️. Observe Layout Changes

Navigation collapses or stacks

Text resizes and rearranges

Images scale proportionally

Sections realign for smaller screens
